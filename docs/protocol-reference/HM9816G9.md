# HM 系列行星关节伺服 HM9816G9 产品规格

> 由同名 PDF 文本提取整理，尺寸图未转换。

## 产品特性
1. 驱动器、编码器、电机、减速器一体化设计。
2. 支持 MIT 控制模式。
3. 提供专用测试上位机。
4. 安装尺寸兼容 OPENARM 设计。
5. 电源通讯接口一进一出，方便接线。

## 电机参数
| 项目 | 参数 |
|---|---|
| 额定电压 | 24 VDC |
| 额定电流 | 20 A |
| 峰值电流 | 50 A |
| 额定扭矩 | 20 Nm |
| 峰值扭矩 | 40 Nm |
| 极对数 | 21 |
| 减速比 | 9:1 |
| 重量 | 0.95 kg |
| 扭矩常数 | 0.45 Nm/A |
| 堵转扭矩 | 60.07 Nm |
| 堵转电流 | 57.75 A |
| 相间电感 | 70 µH |
| 相间电阻 | 0.121 Ω |
| 额定转速 | 100 RPM |
| 最大转速 | 172.9 RPM |
| 编码器 | 14 位，2 个，磁编（单圈输出轴一圈绝对位置） |
| 通讯 | CAN 1 Mbps |

## 接口引脚
| 符号 | 含义 |
|---|---|
| + | 电源正 18~36 V |
| − | GND |
| 1 | CAN H |
| 2 | CAN L |

> 整理注：规格书扭矩常数 0.45 Nm/A，寄存器 kt 读到 0.12，二者关系待实测。
