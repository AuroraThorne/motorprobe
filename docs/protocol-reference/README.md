# MotorProbe 电机资料库

本目录收录 Windows 版 CanMotorKit `reference/` 中的厂家手册、协议转换稿和适配说明副本，供插件开发、协议核对与离线查阅。协议实现以这里的资料和仓库中的测试为依据；资料中标记“待实机验证”的行为仍未经过硬件验证。

- 达妙 DM 与 HM：DM J4310/J6006/J8009P 手册、HM 系列手册及 HM9816G9 记录。两者在本项目支持的 MIT 与 `0x7FF` 报文族中共享驱动实现。
- RoboMaster：C610/C620、M2006、M3508、GM6020、RM 6623 说明书。
- 高擎 GD：经典 CAN 协议和 FDCAN 手册，以及 [`高擎GD适配说明.md`](高擎GD适配说明.md)。VS Code 插件当前只接入经典 CAN；FDCAN 不属于此驱动。
- VESC：留作后续协议参考，当前未接入插件。

GD 厂家资料中没有可核验的电流换算刻度，因此插件不猜测电流单位或启用 GD 电流模式。GD 状态帧没有温度和使能标志，错误码只按 GD 自己的定义处理。所有实际硬件行为仍需按仓库顶层安全约定单独验证。
