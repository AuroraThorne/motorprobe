## 注意事项
- 请按照本文规定的工作参数使用，否则可能对产品造成严重损坏。
- 在电机运行时请勿切换控制方式，如需切换请先发送停止命令。
- 使用前请检查各部件是否完好；请勿随意拆卸电机；确保连接无短路。

## 2. 协议说明

### 2.0 电机指示灯
| 现象 | 含义 |
|---|---|
| 上电后绿灯亮 1 秒、红灯灭，1 秒后绿灯灭红灯常亮 | 硬件初始化成功 |
| 上电后绿红都不亮，1 秒后绿灯不亮红灯常亮 | 多圈初始化失败 |
| 绿灯常亮 | 电机使能 |
| 红灯常亮 | 电机失能 |
| 红灯闪烁 | 驱动器故障报警，需要重新断电上电 |

默认通信协议：CAN 2.0B 标准帧，1 Mbps，每帧数据场固定 8 字节。

滤波器配置：
- 滤波器 0：实时控制帧、模式修改帧（MIT 协议），CAN ID = 电机本机 ID（0~127）。
- 滤波器 1：参数读写查询帧（自定义协议），CAN ID = 0x7FF。
- 电机状态帧应答 ID = MASTER_ID（默认 0）；参数读写帧应答 ID = MASTER_ID。
- 上电默认 CAN ID = 0x01，可通过配置帧修改。

### 2.1 MIT 控制协议
MIT（Mixed Integrated Torque）为力/位混合控制：驱动器将位置环、速度环、前馈扭矩相加得到参考电流，由电流环输出扭矩。

| 帧 | 方向 | ID | 数据 |
|---|---|---|---|
| 控制帧 | 主机→驱动器 | 设备 ID（默认 1） | 位置、速度、Kp、Kd、前馈扭矩 |
| 状态帧 | 驱动器→主机 | 主机 ID（默认 0） | ID、位置、速度、扭矩、温度 |
| 模式切换帧 | 主机→驱动器 | 设备 ID（默认 1） | FF FF FF FF FF FF FF + 模式代码 |

#### 参数与量程
| 参数 | 含义 | 说明 |
|---|---|---|
| kp | 位置比例系数（刚度） | kp=0 时位置环失效 |
| kd | 位置微分系数（阻尼） | 位置控制时需非零，否则振荡 |
| pos | 期望位置 rad | |
| vel | 期望速度 rad/s | |
| torq | 前馈扭矩 Nm | kp=kd=0 时为纯扭矩控制 |

| 量程 | G9 | G36 | G10 |
|---|---|---|---|
| KP | 0, 500 | 0, 500 | 0, 500 |
| KD | 0, 5 | 0, 5 | 0, 5 |
| P | -12.5, 12.5 | -12.5, 12.5 | -12.5, 12.5 |
| V | -45, 45 | -8, 8 | -30, 30 |
| T | -54, 54 | -28, -28（原文如此） | -10, 10 |

> 整理注：实机 HM9816G9 读到 p_max=π（用户修改过），量程以寄存器 0x15~0x17 为准。

#### 控制帧布局（大端位序）
| D0 | D1 | D2 | D3 | D4 | D5 | D6 | D7 |
|---|---|---|---|---|---|---|---|
| p[15:8] | p[7:0] | v[11:4] | v[3:0] \| kp[11:8] | kp[7:0] | kd[11:4] | kd[3:0] \| t[11:8] | t[7:0] |

位宽：p 16，v/kp/kd/t 各 12。定点换算：

```c
int float_to_uint(float x, float x_min, float x_max, int bits) {
    float span = x_max - x_min;
    return (int)((x - x_min) * ((float)((1 << bits) - 1)) / span);
}
float uint_to_float(int x_int, float x_min, float x_max, int bits) {
    float span = x_max - x_min;
    return ((float)x_int) * span / ((float)((1 << bits) - 1)) + x_min;
}
```

#### 状态反馈帧布局
| D0 | D1 | D2 | D3 | D4 | D5 | D6 | D7 |
|---|---|---|---|---|---|---|---|
| ID[3:0] \| ERR[7:4] | pos[15:8] | pos[7:0] | vel[11:4] | vel[3:0] \| t[11:8] | t[7:0] | 见注 | 见注 |

- 参数表写 D6/D7 为 v_margin/temp，打包代码写 t_mos/t_rotor（0~130 ℃）。
- 原文打包代码中扭矩使用了 `T_MIN, V_MAX`，应为笔误。

> 整理注：实测 D6=D7=26，按 MOS/线圈温度理解，与达妙一致。ERR 实测 0=失能、1=使能（手册未写）。

#### 模式切换（特殊帧），ID = 电机 ID，数据 FF×7 + 命令码
| 命令码 | 名称 | 功能 |
|---|---|---|
| 0xFB | CLEAR_ERROR_CMD | 清除报错 |
| 0xFC | MOTOR_CMD | 切换至电机运行模式（使能） |
| 0xFD | MENU_CMD | 切换至菜单/配置模式（待机/失能） |
| 0xFE | ZERO_CMD | 当前位置设为零位，并把位置给定置 0 |

上电自检完毕后需发送「电机运行」命令才可控制；电机上电默认待机，其他指令需先切回待机模式。

#### 使用场景
| 场景 | 参数 |
|---|---|
| 匀速转动 | kp=0，kd>0，pos=0，vel=目标速度，torq=0 |
| 纯扭矩输出 | kp=0，kd=0，pos=0，vel=0，torq=目标扭矩 |
| 点到点位置 | kp>0，kd>0，pos=目标位置，vel=0，torq=0 |
| 混合 | kp>0，kd>0，pos/vel/torq 均给定 |

#### 调试步骤与常见问题
- 先开位置环（kp>0、kd>0），增大 kd 抑制振荡；负载大时加前馈扭矩。
- 电机不转：kp=kd=torque=0；振荡：kd 过小；过流：torque 过大。
- 原文提到「确认 ID 为 0x00+motor_id（位置帧）和 0x01+motor_id（扭矩帧）」，与正文矛盾，按正文（控制帧 ID = 电机 ID）。

## 3.2 自定义协议（参数读写，请求 ID = 0x7FF，应答 ID = MST_ID）
| 功能 | D0 | D1 | D2 | D3 | D4~D7 |
|---|---|---|---|---|---|
| 读参数 | CANID_L | CANID_H | 0x33 | RID | 0 |
| 读应答 | CANID_L | CANID_H | 0x33 | RID | 数据 |
| 写参数 | CANID_L | CANID_H | 0x55 | RID | 数据 |
| 写应答 | CANID_L | CANID_H | 0x55 | RID | 数据 |
| 存储参数 | CANID_L | CANID_H | 0xAA | 0x01 | 空 |
| 读电机状态 | CANID_L | CANID_H | 0xCC | 0 | —（回复 MIT 状态帧） |
| 修改波特率 | CANID_L | CANID_H | 0xAA | 0x23 | D4=索引，其余 0 |

- 数据为 float 或无符号整型，32 位，低位 D4、高位 D7。
- 存储参数只在失能模式下生效。
- 仅 CAN FD 版本支持改波特率，CAN 版固定 1M。索引：1=125k 2=250k 3=500k 4=1M 5=2M 6=2.5M 7=3.2M 8=4M 9=5M。

> 整理注：达妙的波特率索引为 0=125K 1=200K 2=250K 3=500K 4=1M …，与此处从 1 开始不同；实机读到 4（1M）。
