# 高擎 GD 经典 CAN 适配说明

依据用户提供的《1.3 高擎GD电机 CAN 通信协议解析手册》版本 1.0。
原文件保存在本目录的《高擎GD经典CAN通信协议.md》，未作为代理指令执行。

## 已接入

- 用户确认实机型号为 5036-02-CNE，列表单列“GD 5036-02-CNE”，另有 GD 5036/6036 通用及 GD 协议通用选项。1 Mbps，29 位扩展数据帧，ID 1~126。扫描使用 0x07 查询型号，按实际返回的 5036/6036 前缀区分家族；不从状态帧或 ID 猜测型号后缀。
- 扭矩控制 0x1B：0.01 Nm/LSB，负数用 int16 小端补码；软件范围 ±100 Nm，与 MIT 共用输出限制。该范围是协议范围，不是型号额定扭矩。
- 状态 0x0E：位置 0.0001 圈/LSB，速度 0.00025 圈/s/LSB，扭矩 0.01 Nm/LSB；界面统一转换为 rad/rad/s/Nm。
- MIT：按文档 p16/v12/t12/kp12/kd12 拼为小端 64 位；Kp/Kd 保留厂家原生增益刻度，位置误差按圈、速度误差按圈/s计算。
- 扭矩零值精确编码为 1B 0E 00 00。纯扭矩的 MIT 输入也转为这个命令，避免偏移码中点造成非零增益。其余 MIT 输入存在协议固有的量化误差。
- 0x00/0x0E 作为无控制动作的状态查询，用于扫描、空闲以及 MIT 运行期间补充状态请求；需实机确认。
- 开始输出为软件开关；停止输出先发零扭矩，再发 01 0E 自由停转。急停只发零扭矩并锁存，不发送 0x18 阻尼制动。
- 设零点使用 03 03 03，仅在停止输出时可用，不自动保存 Flash。
- 错误码 0 表示正常；非零错误保留原值并触发安全锁存。无温度反馈、无使能状态位。
- 响应辨识、上位机闭环、曲线、CAN 报文解析和所选电机 FPS 复用通用流程。
- 电机参数页提供型号、固件/硬件版本查询、修改 ID、保存到 Flash、重设零位、软重启、周期反馈配置/关闭。系统命令仅停止输出时可用，串行处理，超时自动结束，不自动重发写入、保存、重启等命令。
- 改 ID 先向新 ID 查询状态，已有应答时拒绝覆盖；写入后兼容旧/新 ID 的 03 应答，并必须收到新 ID 的状态才更新软件地址。无应答不能证明总线上没有同 ID 设备，仍需按接线实际核对。改 ID 后单独点保存，程序不自动保存 Flash。
- 软重启在文档中明确无应答，显示“已发送”；周期反馈设置未定义独立应答，同样显示“已发送”，通过实际反馈帧率观察是否生效。
- 型号回复长度超过单帧可容纳的 6 个字符时保留已有 ASCII 字符并注明不完整，不猜测未定义的分包方式。版本按 patch/minor/major 字节顺序转换。查询超时不阻塞后续查询。
- GD 控制页提供电机内部速度、位置、位置+速度/扭矩上限、自由停转、阻尼制动。所有动作须先开始输出、再应用；停止输出、零扭矩和切换模式均清理原生控制目标，避免恢复旧指令。急停仍仅零扭矩，与主动选择阻尼制动区分。
- 原生速度/位置命令不含扭矩上限，不能伪称硬件已限扭矩；左侧输出限幅启用时拒绝这两种命令，提示使用带扭矩上限的模式。位置+速度/扭矩模式同时按左侧限速和限扭矩缩小命令上限；全部原生模式保留状态监督和反馈超时保护。
- 演示台 GD ID6 为 5036、ID7 为 6036，供扫描区分、系统设置、运动控制回归验证；不代表两型号实测机械参数。
